
# Rock Paper Scissors GAME

This game runs a match betwen you and your device the first to win two rounds in a row finishes the game otherwise the game keeps going!

## How it works

When you click on any chose the game will run a random input and decides on what to chose. 
When you score 3 points you win a round if you win two rounds in row you finish the game!
